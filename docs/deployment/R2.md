# Setting Up Cloudflare R2 Object Storage

## 1. Bucket Creation
1. Go to Cloudflare Dashboard -> R2 -> Create Bucket (`autotube-media`).
2. Set bucket access to **Private** (recommended for tenant privacy).

## 2. API Token Generation
1. In Cloudflare R2 dashboard, click **Manage R2 API Tokens**.
2. Create Token with **Object Read & Write** permissions on `autotube-media`.
3. Save:
   - **Endpoint**: `https://<ACCOUNT_ID>.r2.cloudflarestorage.com`
   - **Access Key ID**: `<R2_ACCESS_KEY_ID>`
   - **Secret Access Key**: `<R2_SECRET_ACCESS_KEY>`

## 3. Storage Key Partitioning & Retention
- Files are saved as `users/<user_id>/videos/<video_id>.mp4`.
- AutoTube generates short-lived presigned URLs for client preview or streams directly through the API.
